🤖 本地 AI / 智能体平台

本地模型部署、自托管 AI Agent、低代码工作流与零代码智能体平台完整指南

本页覆盖四类工具：① 在本机运行开源模型（Ollama + Hermes 等）；② 多模型聚合 Agent 自托管平台（OpenClaw）；③ 低代码 AI 工作流与 RAG 平台（Dify、FastGPT）；④ 零代码云端智能体搭建（Coze）。不同层级对应不同技术门槛，请按需选择。

开源本地模型运行框架，支持一键下载并运行 Llama、Hermes、Mistral、Gemma 等数十种主流开源模型。使用简单，无需编写代码，命令行或 Web UI 均可操作。

完全免费 本地离线运行 开源项目

📦 Ollama 安装与使用（详细步骤）

  • 1

    下载安装 Ollama

    前往 ollama.com，点击「Download」按钮，下载对应系统的安装包（Windows: OllamaSetup.exe，约 600MB）。双击运行，按提示安装。安装完成后系统托盘会出现一个羊驼图标，表示 Ollama 已在后台运行。

    Windows 用户注意：Ollama 安装后自动以系统服务方式运行，不需要手动启动。如果托盘没有图标，打开「开始菜单」搜索「Ollama」点击启动。

  • 2

    打开终端

    Windows：按 Win + R，输入 cmd 回车，打开命令提示符。或搜索「PowerShell」打开。
    验证安装：输入以下命令，如果显示版本号说明安装成功：
    ollama --version

  • 3

    下载并运行你的第一个模型

    在终端中输入（推荐新手先用小模型体验）：
    ollama run qwen2.5:0.5b
    这个模型只有 0.5B 参数，约 400MB，几秒钟就能下载完成。下载完成后终端会显示 >>> 提示符，表示可以开始对话了。
    试试输入：「你好，介绍一下你自己」，看看效果。

  • 4

    试试更大的模型（如果电脑配置允许）

    退出当前对话输入 /bye，然后尝试更大的模型：
    ollama run qwen2.5:7b（中文优秀，约 4.5GB，推荐 8GB+ 内存）
    ollama run deepseek-r1:7b（推理强，约 4.7GB）
    ollama run hermes3（Agent 优化，约 4.9GB）

  • 5

    管理已下载的模型

    查看已安装模型：ollama list
    删除不需要的模型：ollama rm 模型名（释放磁盘空间）
    查看模型信息：ollama show 模型名

  • 6

    （可选）安装 Open WebUI 图形界面

    Ollama 默认是命令行界面。如果你想要类似 ChatGPT 的网页聊天界面：
    ① 确保已安装 Docker Desktop（参考上方的 Dify 安装教程第 1 步）
    ② 在终端执行：docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main
    ③ 打开浏览器访问 http://localhost:3000，注册账号后即可在网页中使用本地模型。

硬件要求参考：7B 模型需要约 4–8 GB 显存或内存；13B 需要约 8–16 GB；70B 模型需要 48 GB+ 以上显存，一般消费级电脑难以运行。若电脑配置不高，建议选择 1.5B–7B 的轻量模型（如 DeepSeek-R1:1.5b 或 Gemma2:2b）。

Hermes Agent 模型系列

Hermes 是由 NousResearch 开发的开源大语言模型系列，基于 Meta Llama 架构进行专项微调，在指令跟随、角色设定（System Prompt）、函数调用（Function Calling）和 Agent 任务执行方面表现突出，被广泛用于需要自定义行为的本地 AI Agent 场景。

Agent 专项优化 开源免费 via Ollama 运行
HuggingFace ↗ GitHub ↗

Hermes 系列版本对比

版本 基础模型 参数量 核心优势 Ollama 命令
Hermes 3 Llama 3.1 8B / 70B / 405B 指令跟随、Function Calling、多步 Agent ollama run hermes3
Hermes 2 Pro Mistral 7B 7B JSON 输出格式、工具调用稳定 ollama run hermes2-pro-mistral
Hermes 2 Theta Llama 3 8B / 70B 对话流畅度与角色扮演 ollama run hermes2-theta
适用场景：Hermes 系列特别适合用在需要严格遵循 System Prompt 设定的场景，例如：搭建有固定人设的本地 AI 助手、在 OpenClaw 等 Agent 平台中作为后端推理模型、需要稳定输出 JSON 格式供程序解析的自动化任务。

自托管部署 20+ 平台接入 6+ 本地模型 数据私有化 智能体编排
🦀

OpenClaw AI Agent

将分散的 AI 模型和平台统一管理，在私有化部署的前提下实现多模型协同、任务编排与 Agent 工作流，适合对数据隐私有较高要求、或希望统一管理多个 AI 账号的用户和团队。

自托管部署 多模型聚合 数据私有化

核心能力

部署要求：OpenClaw 属于自托管项目，部署需要具备一定的服务器运维基础（Docker 或 Node.js 环境），适合有一定技术背景或愿意学习部署流程的用户。

📦 OpenClaw 本地部署步骤

  • 1

    准备环境

    确保已安装 Node.js 18+（访问 nodejs.org 下载 LTS 版本）和 Git（访问 git-scm.com 下载）。打开终端验证：node -v 显示 v18+，git -v 显示版本号。

  • 2

    获取 OpenClaw 代码

    从 OpenClaw 官方仓库克隆代码（或下载 ZIP 解压）：
    git clone https://github.com/你的仓库/openclaw.git
    cd openclaw

  • 3

    安装依赖并启动

    执行以下命令安装项目依赖并启动服务：
    npm install
    npm run dev
    启动成功后，终端会显示访问地址，通常为 http://localhost:3000。在浏览器中打开即可进入 OpenClaw 管理界面。

  • 4

    配置模型接入

    在 OpenClaw 设置页面中，添加你要使用的 AI 服务：
    ① 填入 Claude API Key（从 anthropic.com 获取）
    ② 填入 OpenAI API Key（可选，从 platform.openai.com 获取）
    ③ 配置 Ollama 本地模型地址（默认 http://localhost:11434）
    配置完成后即可在统一界面中使用所有接入的模型。

⚡

Dify

由 LangGenius 开发的开源 AI 应用开发平台，支持本地自部署（Docker）或云端托管，提供可视化工作流编排、RAG 知识库管理、Agent 配置等功能。在国内开源社区有很高的使用率。

开源免费 可视化工作流 RAG 知识库 需自行部署
官网 ↗ GitHub ↗

主要功能

  • ✓
    可视化 Workflow 编排：拖拽节点构建多步 AI 处理流程，无需写代码。
  • ✓
    RAG 知识库：将企业文档、PDF 等资料接入 AI，让模型「读懂」自有数据后再回答。
  • ✓
    多模型切换：同一工作流可自由切换使用 OpenAI、Anthropic、国产大模型或 Ollama 本地模型。
  • ✓
    Agent 模式：内置 ReAct、Function Calling 等 Agent 执行框架，可接入网络搜索、代码解释器等工具。
Dify vs OpenClaw：Dify 更专注于「构建 AI 应用」（知识库问答、工作流自动化），适合有应用开发需求的场景；OpenClaw 更专注于「统一管理多个 AI 账号和模型」，适合多平台重度使用者。两者可以结合使用。

📦 Dify 安装部署教程（Windows Docker 方式）

  • 1

    安装 Docker Desktop

    访问 docker.com/products/docker-desktop，下载 Windows 版并安装。安装完成后重启电脑，打开 Docker Desktop 确认左下角显示「Engine running」。

    ⚠️ 前提要求：Windows 10/11 64位，需在 BIOS 中启用虚拟化（Virtualization）。如果没有启用，Docker 启动时会报错提示。

  • 2

    下载 Dify 源码

    打开终端（PowerShell），执行以下命令克隆 Dify 代码：
    git clone https://github.com/langgenius/dify.git
    cd dify/docker

  • 3

    启动 Dify

    在 docker 目录下执行：
    docker compose up -d
    首次运行会自动下载所有需要的镜像，大约需要 5-15 分钟（取决于网速）。完成后终端显示所有容器状态为「Up」。

  • 4

    初始化管理员账号

    打开浏览器，访问 http://localhost/install，按照向导设置管理员邮箱、用户名和密码。完成后自动跳转到 Dify 主界面。

  • 5

    创建第一个应用

    点击「创建应用」→ 选择「聊天助手」→ 输入名称 → 在模型提供商中添加 OpenAI/DeepSeek 等 API Key（或在设置中接入 Ollama 本地模型）→ 开始对话测试。

硬件要求：推荐至少 4GB 内存。如果你的电脑配置较低，也可以直接使用 Dify 云服务版（dify.ai），免费版提供基础功能，无需本地部署。

零代码智能体平台（云端）

无需部署服务器，在浏览器中直接搭建自定义 AI 智能体，适合技术门槛低的用户快速实现想法

🔧

Coze（扣子）

由字节跳动推出的零代码 AI 智能体搭建平台（国内版为「扣子」coze.cn，国际版为 coze.com）。无需任何编程基础，通过可视化配置即可搭建有特定功能的 AI 助手，并发布到微信、飞书等平台。

国内直连 免费可用 零代码搭建 字节跳动出品
扣子（国内版）↗ Coze（国际版）↗

Coze 能做什么？

  • ✓
    搭建自定义 AI 助手：设定角色、知识库、技能插件，做出有特定功能的专属 AI。
  • ✓
    接入多款模型：国内版可选豆包、通义、DeepSeek；国际版支持 GPT-4、Claude 等国际模型（需相应 API Key）。
  • ✓
    发布到多平台：搭建好的 Bot 可一键发布到微信客服、飞书、微信小程序、网页等渠道。
  • ✓
    工作流与自动化：通过 Workflow 功能，配置多步骤的 AI 处理流程，例如：搜索 → 总结 → 生成报告。

🚀 从零搭建你的第一个 Bot（详细步骤）

  • 1

    注册账号

    访问 coze.cn（国内版），用手机号或抖音/头条账号直接登录。国际版访问 coze.com，用 Google 账号登录。

  • 2

    创建 Bot

    登录后点击左侧「工作空间」→「创建智能体」，输入名称（如「我的学习助手」）和功能描述（如「帮我解答编程问题和学习规划」），点击确认。

  • 3

    编写人设与回复逻辑

    在「人设与回复逻辑」区域输入 System Prompt，例如：
    你是一位耐心的编程学习助手。用通俗易懂的语言解答编程问题，每次回答后附上一个相关的练习题帮助巩固。

  • 4

    （可选）添加知识库

    如果你希望 Bot 基于特定资料回答问题，点击「知识库」→「添加知识库」→ 上传 PDF/Word 文档或输入网页链接。例如上传你的课程笔记，Bot 就能基于笔记内容回答问题。

  • 5

    测试对话

    在右侧预览区域直接输入问题测试效果。例如输入「Python 怎么读取 CSV 文件？」，观察 Bot 的回答质量，不断调整 System Prompt 直到满意。

  • 6

    发布 Bot

    点击右上角「发布」，选择发布渠道。国内版支持：微信客服、微信公众号、飞书、网页。发布后用户即可直接与你的 Bot 对话。

注意：Coze 的数据存储在字节跳动云端服务器，不适合处理高度敏感的私人数据。如有数据私有化需求，建议考虑 OpenClaw 或 Dify 自部署方案。

AI 编程开发助手

AI 辅助编写代码、构建应用、调试排错，大幅提升开发效率，即使编程基础薄弱也能做出成品

📝

Cursor

基于 VS Code 深度定制的 AI 编程编辑器，内嵌 AI 对话和代码生成能力。支持 Claude、GPT-4o、DeepSeek 等多种模型，可以直接在编辑器中和 AI 对话来生成、修改、解释代码，是目前最流行的 AI 编程工具。

最热门 AI IDE 免费基础版 多模型支持
官网 ↗

📦 安装配置 Cursor（详细步骤）

  • 1

    下载 Cursor

    打开 cursor.com，点击「Download for Windows」（Windows 用户）或对应系统按钮。下载的是 .exe 安装包（约 150MB）。

  • 2

    安装

    双击下载的 Cursor-Setup.exe，按提示一路「Next」即可完成安装。默认安装路径为 C:\Users\你的用户名\AppData\Local\Programs\cursor。安装完成后桌面会出现 Cursor 图标。

  • 3

    登录账号

    首次打开 Cursor 会要求登录。可以用 Google 账号或 GitHub 账号一键登录。免费版每月有 2000 次高级模型请求额度，日常使用足够。

  • 4

    选择 AI 模型

    登录后在设置中选择默认模型：推荐 Claude 3.7 Sonnet（代码能力强），备选 GPT-4o。路径：Settings → Models → 选择 Claude 3.7 Sonnet。

  • 5

    第一次使用：让 AI 帮你写一个网页

    按 Ctrl+N 新建文件，按 Ctrl+J 打开 AI 对话面板，输入：
    帮我创建一个个人主页 HTML 文件，包含名字、简介和联系方式
    Cursor 会自动生成代码。点击「Accept」接受，然后按 Ctrl+S 保存为 index.html，双击即可在浏览器中预览。

新手推荐：Cursor 是目前对编程新手最友好的 AI 编程工具。界面和 VS Code 几乎一致，有大量中文教程。用自然语言描述你想做的功能，AI 会帮你写代码。
快捷键速记：Ctrl+K 选中代码后用自然语言修改；Ctrl+L 打开侧边 AI 对话；Ctrl+I 打开 Composer 多文件编辑；Tab 接受 AI 建议。

腾讯云出品 免费可用 小程序+IDE
官网 ↗

WorkBuddy 的特色在于可以通过微信小程序在手机上直接下达开发任务，电脑端 IDE 自动执行。适合需要在移动端远程管理项目、或希望通过对话式交互完成开发工作的用户。支持 Python、Node.js、HTML/CSS/JS 等多种语言。

ChatGPT GPTs

OpenAI 推出的自定义 AI 助手功能，无需编程即可创建有特定能力和知识的专属 AI 助手。用户可以自定义 System Prompt、上传知识文件、配置外部 API 调用，然后在 ChatGPT 中直接使用。

需 ChatGPT 账号 零代码自定义 OpenAI 出品
GPTs 商店 ↗

GPTs 能做什么？

  • ✓
    定制化 AI 助手：设定角色和指令，让 ChatGPT 按特定风格和规则回答。
  • ✓
    知识库：上传文档，GPT 基于你的资料回答问题（类似轻量版 RAG）。
  • ✓
    外部 API 调用：配置 Actions，让 GPT 调用外部服务（如查询天气、搜索数据库）。
  • ✓
    GPTs 商店：浏览和使用全球用户创建的数百万个 GPTs，找到现成的解决方案。
GPTs vs Coze：GPTs 基于 ChatGPT 生态，国际功能更丰富，但需访问 ChatGPT；Coze 由字节跳动出品，国内直连，更方便接入国内平台（微信、飞书等）。两者定位类似，按网络条件选择。
