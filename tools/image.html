Midjourney

公认的 AI 绘图天花板，通过 Discord 使用，以极高的图像质量和丰富的艺术风格著称。由 Midjourney Inc. 开发，2022年发布，已迭代至 V6 版本。

国际顶级 订阅制 $10/月起 需国际访问
官网 ↗ 官方文档 ↗ 工具对比

Midjourney 是什么？

Midjourney 是一款 AI 图像生成工具，用户通过输入文字描述（Prompt），即可在数十秒内生成高质量图像。当前版本 V6 在写实、插画、概念设计、摄影风格等各方面表现均为行业领先。

Midjourney 的特色在于：艺术风格多样性（油画、水彩、像素风、3D 渲染等）、极高的细节控制（通过参数精确控制比例、风格化程度、版本等）、活跃的社区生态（Discord 社区内可观看他人创作并学习 Prompt 写法）。

注意：Midjourney 通过 Discord 运行，不支持中国大陆手机号注册 Discord。需要国际邮箱（Gmail 等）或手机号，并具备国际网络访问能力。

如何访问 Midjourney？

  • 1

    注册 Discord 账号

    访问 discord.com 注册，建议使用 Gmail 邮箱，无需绑定手机号也可注册成功。

  • 2

    加入 Midjourney 官方服务器

    访问 midjourney.com，点击「Join the Beta」，会跳转到 Discord 邀请链接，接受后进入 Midjourney 服务器。

  • 3

    选择订阅方案

    在 /subscribe 页面选择方案：Basic（$10/月，约200张图/月）、Standard（$30/月，15小时快生成）、Pro（$60/月）。也可通过第三方平台购买。

快速上手

  • 1

    找到生成频道

    进入 Midjourney 服务器，在左侧频道列表找到以 newbies- 开头的频道（新手频道）。

  • 2

    输入 Prompt 生成图片

    输入 /imagine 命令，在 prompt 字段用英文描述你想要的画面，按回车即可。例如：
    /imagine a cute cat sitting on a windowsill, watercolor style --ar 16:9

  • 3

    选择并放大

    生成 4 张候选图后，点击 U1-U4 放大单张，点击 V1-V4 基于该张变体再生成。放大完成后可直接下载。

进阶技巧

常用参数

参数作用示例
--ar画面比例--ar 16:9（横屏）--ar 9:16（竖屏）
--v模型版本--v 6.1（最新版）
--s风格化程度（0-1000）--s 250（中等艺术化）
--q图像质量--q 2（高画质）
--no排除元素--no text, watermark
--cref角色一致性参考--cref URL

垫图技巧（Image Prompt）

在 /imagine 后先粘贴图片URL或直接拖拽图片，再写文字描述，Midjourney 会基于参考图的构图/色调/风格生成新图。适合风格迁移、角色一致、产品场景图等。

Prompt 写作核心原则：主体描述在前（"a beautiful woman"），风格/氛围在后（"cinematic lighting, 8K, highly detailed"），参数在最后（"--ar 3:4 --v 6.1"）。中文 Prompt 需翻译为英文效果更佳。

📦 Fooocus 安装教程（Windows 详细步骤）

  • 1

    确认硬件环境

    按 Win + R，输入 dxdiag 回车，在「显示」选项卡查看显卡型号。需要 NVIDIA 显卡（GTX 1060 6GB 或更高，推荐 RTX 3060 12GB+）。如果没有 NVIDIA 显卡，也可以用 CPU 模式，但速度很慢。
    如果没有 NVIDIA 显卡但想体验 AI 绘图，推荐使用网页版工具（即梦AI / 通义万象 / Midjourney）。

  • 2

    下载 Python

    访问 python.org/downloads，下载 Python 3.10.x（推荐 3.10.11）。安装时务必勾选「Add Python to PATH」（这一步非常重要！）。安装完成后打开命令提示符输入 python --version，显示版本号即成功。

  • 3

    下载 Fooocus

    访问 github.com/lllyasviel/Fooocus，点击页面右侧的「Releases」，下载最新版本的 Fooocus_win64_xxxx.zip（约 200MB）。解压到任意文件夹（如 D:\Fooocus）。

  • 4

    首次启动

    进入解压目录，双击运行 run.bat。首次启动会自动下载模型文件（SDXL 约 6GB + 其他文件约 2GB），需要等待 10-30 分钟（取决于网速）。
    终端显示「Running on local URL: http://127.0.0.1:7865」时，表示启动成功。

  • 5

    开始生成图片

    浏览器自动打开 http://127.0.0.1:7865（如果没有，手动打开）。在输入框中用中文或英文描述画面，例如：
    一只橘猫坐在窗台上，窗外是雨天的城市街道，温暖的灯光，电影感
    选择风格（推荐「Fooocus V2」或「Fooocus Photograph」），点击「Generate」生成。通常 10-30 秒出图。

硬件要求：显存 4GB 可运行（需要较小模型），6GB+ 流畅运行 SDXL，8GB+ 可运行高清大图。无 NVIDIA 显卡也可使用 CPU 模式，但速度非常慢。

DALL·E 3

OpenAI 开发的 AI 绘图模型，内置于 ChatGPT 中。最大的优势是自然语言交互——用日常语言描述即可精准生成图像，对 Prompt 的格式要求最低。

ChatGPT 内置 需国际访问
通过 ChatGPT 使用 ↗

使用方式：在 ChatGPT 中直接对话式描述你要的图片，例如「帮我画一只穿宇航服的柴犬，站在月球上，卡通风格」。ChatGPT 会自动优化描述并生成图片。免费版用户每日有限额，ChatGPT Plus（$20/月）用户使用更多。
