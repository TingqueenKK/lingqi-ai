💬 AI 对话助手

国内外主流对话 AI 完整指南，含访问方式、注册步骤、上手教程与进阶技巧

🦞

Claude（小龙虾）

由美国 Anthropic 公司开发，以长文本理解、代码能力和指令精准执行著称。用户亲切地称其为「小龙虾」，来源于 Anthropic 品牌的橙红配色。

国际顶级 长文本强 代码出色 需国际访问
访问官网 ↗ 与其他工具对比

Claude 是什么？

Claude 是 Anthropic 公司开发的大型语言模型系列，当前最新版本为 Claude 3.7 Sonnet（2025年发布）。Anthropic 由前 OpenAI 核心成员创立，专注于 AI 安全性研究。

Claude 系列模型分为多个档位：Haiku（速度快、成本低）、Sonnet（性能与速度平衡，最常用）、Opus（能力最强）。

Claude 的核心优势

  • ✓
    超长上下文窗口：Claude 3.7 支持最高 20 万个 token 的上下文，可一次性处理整本书的内容。
  • ✓
    代码与技术能力：在 SWE-bench 等代码基准测试上持续位居前列，能独立完成复杂编程任务。
  • ✓
    指令遵循精准：格式要求、角色扮演、多步任务执行能力强，不容易「跑偏」。
  • ✓
    中英文均衡：虽然以英文为主要训练语言，但中文理解和生成质量同样出色。
定位参考：如果你需要处理长文档、撰写高质量长文、进行复杂代码任务，Claude 是优先选择。日常问答、短文本场景，国内工具（Kimi、豆包等）更方便且无需额外访问步骤。

如何访问 Claude？

🌐 方式一：直接访问官方网站（推荐）

访问 claude.ai，注册账号后即可使用。免费版有每日使用额度限制，付费版（Claude Pro，约 $20/月）无限制使用 Sonnet 模型，并优先访问 Opus。

📱 方式二：官方移动应用

Anthropic 提供 iOS 和 Android 官方 App。iOS 用户可在 App Store（美区账号）下载；Android 用户可在 Google Play 下载。

🇨🇳 方式三：国内第三方平台（无需自行访问国际版）

多款国内 AI 平台已接入 Claude 模型，可直接在国内访问使用，例如：字节扣子（Coze）内置 Claude 选项；部分 API 聚合平台也提供 Claude 接口。这是新手最省心的入门方式。

注意：claude.ai 不支持中国大陆手机号注册，需要使用国际手机号或第三方登录（Google / Apple 账号）。

快速上手 Claude

  • 1

    打开 claude.ai

    在浏览器地址栏输入 claude.ai，点击「Sign Up」注册。

  • 2

    选择登录方式

    推荐使用 Google 账号或 Apple 账号登录，无需额外绑定手机号。

  • 3

    开始第一次对话

    在底部输入框输入任何问题，按回车发送。例如：「你好，我是第一次使用 AI，能介绍一下你自己吗？」

  • 4

    上传文件（可选）

    点击输入框左侧的 📎 图标，可上传 PDF、Word 等文档，Claude 会阅读并回答你关于文档的问题。

新手建议：第一次用不知道说什么？直接把你工作中遇到的一个实际问题发给 Claude，比如「帮我写一封请假邮件，原因是家里有事需要请 2 天假」。

进阶使用技巧

① 使用 System Prompt 设定角色

在 Claude 的「Project」功能中，可以设置持久的系统指令，让 Claude 在整个项目中保持固定角色，例如「你是一位专业的中文校对编辑，帮我检查文章的语法和逻辑问题」。

② 分步骤提问（Chain of Thought）

复杂任务不要一次性交给 Claude，而是分步骤：先让它分析问题，再让它给出方案，最后让它执行方案。这样能大幅提升输出质量。

③ Artifacts 功能

Claude 的 Artifacts 功能可以将代码、文档、图表等内容在独立窗口中展示和实时预览，特别适合网页开发和文档编写场景。

进阶学习：想深度掌握 AI 提示词技巧，前往 进阶提升路径 查看完整的 Prompt Engineering 教程。

ChatGPT

由美国 OpenAI 公司开发，2022 年 11 月发布，是现代 AI 对话助手的开创者，全球注册用户超过 3 亿。当前主力模型 GPT-4o 在综合能力方面表现优异。

全球最广泛 插件生态丰富 需国际访问
访问官网 ↗ 与其他工具对比

ChatGPT 是什么？

ChatGPT 是 OpenAI 公司开发的 AI 对话工具，当前主力模型为 GPT-4o。它不仅能进行文字对话，还支持图片识别、文件上传分析、联网搜索、图片生成（DALL·E 3 内置）、数据分析与绘图（Code Interpreter）、自定义 GPT（GPTs 商店）等丰富功能。

ChatGPT 有免费版和付费版（ChatGPT Plus，$20/月）。免费版每日有限额使用 GPT-4o，Plus 用户可无限使用 GPT-4o、GPT-4 等模型，并优先使用新功能（如图片生成、高级数据分析等）。

如何访问 ChatGPT？

  • 1

    访问 chatgpt.com

    在浏览器输入 chatgpt.com，点击「Sign Up」注册。需要国际邮箱（Gmail、Outlook 等），不支持中国大陆手机号。

  • 2

    邮箱验证

    填写邮箱后查收验证邮件，点击链接完成验证。

  • 3

    开始使用

    注册完成后直接在页面底部输入框对话。免费用户直接可用 GPT-4o 模型。

注意：chatgpt.com 不支持中国大陆手机号注册，需要国际网络访问能力。国内用户可通过百度文心一言、豆包、Kimi 等国产替代品获得类似体验。

ChatGPT 能做什么？

  • ✓
    文字创作与编辑：写邮件、写文章、翻译、总结文档、润色修改
  • ✓
    代码编写与调试：支持 Python、JavaScript 等主流语言，可解释代码
  • ✓
    图片识别与分析：上传图片，让 AI 描述、分析、提取文字
  • ✓
    联网搜索：开启搜索功能后可获取实时信息
  • ✓
    图片生成：直接用文字描述生成图片（DALL·E 3）
🌙

Kimi

由北京月之暗面科技开发，2023 年发布。以超长上下文能力著称，支持最长约 200 万字的文档处理。擅长文档阅读、论文分析、长文总结等场景。

国内直连 免费可用 长文本强
官网 ↗ 官方新手指南 ↗

快速上手 Kimi

  • 1

    访问 kimi.moonshot.cn

    国内直接访问，无需特殊设置。也可下载手机 App。

  • 2

    手机号注册

    支持中国大陆手机号注册，验证码登录即可。也可用微信扫码登录。

  • 3

    上传文档提问

    点击左侧 📎 按钮上传 PDF、Word、Excel 等文件，然后提问。例如：「总结这份 PDF 报告的 5 个核心要点」「找出这份合同中需要注意的法律条款」。

  • 4

    联网搜索

    Kimi 支持联网搜索模式，点击左上角开关即可开启，适合查询最新信息。

Kimi 最佳使用场景：① 长文档/论文速读（一次上传整本 PDF）；② 网页内容整理（粘贴长文章让 AI 总结）；③ 学术研究辅助（分析多篇论文并提取关键观点）。
🔍

DeepSeek

由杭州深度求索开发。2025 年初 DeepSeek-R1 模型以低成本实现超越同期国际顶级模型的推理性能，引发全球关注。当前已发布 V4 系列模型。

国内直连 免费可用 推理能力强
官网 ↗ 公司官网 ↗

DeepSeek 的独特能力

  • ✓
    「深度思考」模式：点击后 AI 会先展示完整推理过程再给出答案，适合数学题、逻辑题、代码调试等需要一步步思考的场景。非常适合用来学习解题思路。
  • ✓
    代码与数学：在数学推理、代码编写和调试方面表现出色，可使用在线代码运行环境验证结果。
  • ✓
    开源生态：DeepSeek 模型完全开源，可通过 Ollama 在本地运行，适合隐私敏感场景。

快速上手

  • 1

    访问 chat.deepseek.com

    国内直接访问，手机号或邮箱注册。

  • 2

    选择模式

    普通问题用「通用」模式即可；复杂问题（数学、代码、逻辑）开启「深度思考」模式。

  • 3

    上传文件（可选）

    支持上传文档，可让 DeepSeek 基于文档内容进行分析和回答。

高峰期提示：DeepSeek 官网在高流量时段可能出现排队等待，建议错峰使用或通过百度、阿里云等接入了 DeepSeek 的国内平台使用。
🫘

豆包

字节跳动于 2023 年发布的 AI 助手，底层基于字节自研的豆包大模型。支持文字对话、图片生成、实时语音对话、联网搜索等功能，有网页版和手机 App。

国内直连 免费可用 多模态
官网 ↗

豆包的核心功能

  • ✓
    AI 对话：日常问答、写作、翻译、学习辅导
  • ✓
    AI 画图：输入描述即可生成图片（集成即梦AI能力）
  • ✓
    语音对话：像打电话一样与 AI 实时语音交流
  • ✓
    联网搜索：实时搜索互联网信息回答问题
登录便捷：豆包支持抖音/头条/西瓜视频等字节系账号直接登录，对这些平台的老用户最为方便。手机端在各大应用商店搜索「豆包」即可下载。
🌿

通义千问

阿里巴巴集团旗下 AI 助手，底层为阿里云通义大模型（Qwen）。企业级应用生态完善，支持长文本处理、多模态输入（文字+图片），并可通过阿里云 API 接入企业应用。

国内直连 免费可用 企业级生态
官网 ↗ 对话版 ↗

通义千问是阿里云推出的 AI 大模型系列，分为免费对话版和付费 API 版。对话版支持长文档阅读、图片理解、代码编写等。在中文理解、文档处理、代码能力方面表现优秀。阿里云账号（支付宝账号可关联）即可登录使用。

通义千问亮点：模型完全开源（GitHub 搜索 Qwen），可本地运行；阿里云生态完善，适合企业级集成部署。
