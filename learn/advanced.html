🚀 深度应用

AI Agent 搭建、本地模型部署、自动化工作流、应用发布上架等专业级 AI 应用

前置要求：本页内容适合已掌握 AI 基础使用（对话、绘图、音乐）的用户。如果你还没有用过 AI 工具，建议先完成 零基础入门。

🤖 AI Agent（智能体）搭建

智能体是 AI 的进阶形态——不只是对话，而是能自主执行任务、调用工具、处理复杂工作流的 AI 系统。

🔧 Coze 扣子（零代码）

无需编程，可视化搭建 AI 智能体，可发布到微信/飞书。适合非技术人员。

🦀 OpenClaw（自托管）

多模型聚合 Agent 平台，20+ 平台统一管理，数据完全私有。

⚡ Dify（工作流平台）

可视化 RAG 知识库 + 工作流编排 + Agent 框架，适合企业应用开发。

🔧 Coze 扣子：10分钟搭建你的第一个智能体

  1. 注册账号：打开 coze.cn，手机号注册登录
  2. 创建智能体：点击「创建智能体」→ 填写名称（如"学习助手"）→ 选择模型（推荐豆包）→ 填写人设描述（如"你是一位专业的考研辅导老师，擅长梳理知识点"）
  3. 添加插件：在「插件」栏搜索并添加「网页搜索」「图片生成」等插件
  4. 编写开场白：在「开场白」栏设置欢迎语，如"你好！我是你的考研学习助手，请问你想复习哪个科目？"
  5. 添加知识库（可选）：上传 PDF/Word 文档，让 AI 基于你的资料回答问题
  6. 测试运行：点击右侧预览区的对话框，直接和你的智能体对话测试
  7. 发布上线：点击右上角「发布」→ 选择发布到「飞书」或「微信公众号」→ 确认发布

💡 Coze 的优势是零代码、可视化，从创建到发布全程鼠标操作，适合所有技术水平的用户。

🦀 OpenClaw：自托管多模型 Agent 部署指南

前置条件：已安装 Docker Desktop（下载地址），电脑至少 8GB 内存。

  1. 获取项目：从 OpenClaw 官方获取 docker-compose.yml 配置文件
  2. 配置环境：在项目目录下创建 .env 文件，填入各 AI 平台的 API Key（按需配置）
  3. 启动服务：打开终端执行 docker compose up -d，等待所有容器启动完成
  4. 访问面板：浏览器打开 http://localhost:3000，进入管理后台
  5. 配置模型：在「模型管理」中添加已配置 API Key 的模型提供商
  6. 创建 Agent：在「智能体」页面新建 Agent，选择使用的模型、设定人设、配置工具
  7. 测试部署：在对话框中测试 Agent 响应，确认功能正常
注意：OpenClaw 需要基础命令行和 Docker 操作能力。如果这些概念陌生，建议先学完 Coze 再来。

⚡ Dify：搭建知识库问答 Agent

前置条件：已安装 Docker Desktop。

  1. 一键部署：终端执行 git clone https://github.com/langgenius/dify.git && cd dify/docker && docker compose up -d
  2. 初始化设置：浏览器打开 http://localhost，设置管理员账号密码
  3. 创建知识库：进入「知识库」→ 新建 → 上传文档（PDF/Word/TXT）→ 等待向量化完成
  4. 创建应用：进入「工作室」→ 创建「聊天助手」→ 关联上一步的知识库
  5. 编排工作流：在编排页面拖拽「开始」「LLM」「知识检索」「回答」节点，连线形成工作流
  6. 选择模型：可使用 Ollama 本地模型或接入 OpenAI/DeepSeek API
  7. 发布使用：点击右上角「发布」→ 生成 WebApp 链接，直接分享给他人使用

💡 Dify 的 RAG 知识库功能非常适合企业内部文档查询、产品客服问答等场景。

🖥️ 本地模型部署

在自己的电脑上运行 AI 模型，数据完全不出本机，适合隐私敏感或离线场景。

📋 硬件要求速查

方案最低配置推荐配置
Ollama + Qwen 1.5B4GB 显存 / 8GB 内存8GB 显存
Ollama + Qwen 7B8GB 显存12GB 显存
Ollama + Llama 3.1 70B48GB 显存80GB 显存 (A100)
Fooocus AI 绘图8GB 显存12GB 显存

推荐部署方案

  • 最简单方案：Ollama + Fooocus（AI绘图）—— 安装即用，命令行一条搞定
  • 进阶方案：Ollama + Open WebUI —— 浏览器图形界面，像用 ChatGPT 一样用本地模型
  • 专业方案：Ollama + Dify —— 本地模型 + RAG 知识库 + Agent 工作流
  • Agent 方案：Ollama（本地模型）+ OpenClaw（Agent框架）—— 搭建私有化 AI Agent 系统

🦙 Ollama + Open WebUI：本地 ChatGPT 替代方案（7步）

  1. 安装 Ollama：打开 ollama.com/download，下载 Windows 版安装包，双击安装
  2. 下载模型：打开终端（PowerShell）执行 ollama run qwen2.5:7b，首次运行自动下载（约 4.4GB）
  3. 测试模型：下载完成后直接在终端输入问题测试，输入 /bye 退出
  4. 安装 Open WebUI：终端执行 docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main
  5. 访问界面：浏览器打开 http://localhost:3000，注册第一个账号（即管理员）
  6. 关联模型：在设置中确认 Ollama 连接正常，界面左上角即可选择已下载的模型
  7. 开始使用：和 ChatGPT 一样对话即可，所有数据完全在本地处理，无需联网

💡 这个方案是本地 AI 最推荐的入门路线，拥有图形界面，体验接近 ChatGPT。
